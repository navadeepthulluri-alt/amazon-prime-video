# Amazon Prime Video Academic Website

Prime Video-style frontend for the Supabase database mini-project.

## Connect Supabase

Open `js/supabase.js` and replace:
- PASTE_YOUR_SUPABASE_PROJECT_URL
- PASTE_YOUR_SUPABASE_ANON_KEY

Get these from Supabase Dashboard -> Project Settings -> API.

## Expected tables

users, genres, movies, subscriptions, watch_history, ratings, payments

## Run

Open this folder in VS Code and use Live Server on `index.html`.

This is an academic Prime Video-style interface, not an official Amazon system.
