# Prime Video Style Academic Website

1. Open js/supabase.js.
2. Replace SUPABASE_URL and SUPABASE_ANON_KEY with your Supabase Project URL and anon/public key.
3. Commit the folder to GitHub.
4. Enable GitHub Pages.
5. Open index.html through GitHub Pages.

The home page has multiple Prime Video-style horizontal rails, a hero area, hover play buttons, movie details and trailer modal.
